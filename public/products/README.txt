LAVISH FURNITURE — PRODUCT GALLERIES
====================================

Drop product photos into the matching folder below and they appear
automatically on that category's page (refresh in dev, rebuild for production).

Supported formats: .jpg .jpeg .png .webp .avif .gif
Files are shown in name order — name them 01.jpg, 02.jpg, 03.jpg... to control order.
The first image becomes the large featured image; the rest fill the grid.

  carving-sofas/        -> /collections/carving-sofas
  luxury-sofas/         -> /collections/luxury-sofas
  recliners/            -> /collections/recliners
  bedroom/              -> /collections/bedroom
  dining-sets/          -> /collections/dining-sets
  office-furniture/     -> /collections/office-furniture
  wardrobes/            -> /collections/wardrobes
  luxury-chairs/        -> /collections/luxury-chairs
  wooden-decor/         -> /collections/wooden-decor
  coffee-side-tables/   -> /collections/coffee-side-tables

Until you add photos, each page shows elegant "Photos coming soon" placeholders.
Tip: keep each image under ~400 KB (resize to ~1600px wide) for fast loading.
